# Customer Churn Prediction AI

An end-to-end Machine Learning web app that predicts telecom customer churn with an interactive UI.

## Tech Stack
Python · Pandas · Scikit-learn · SMOTE · Streamlit

## Model Performance
- Decision Tree Classifier
- Accuracy: 82% (with SMOTE class balancing)

## Features
- Input customer data via interactive UI
- Predicts churn probability in real-time
- Shows Stay/Churn result with confidence score

## Dataset
Telco Customer Churn — 7,043 rows, 21 columns (Kaggle)
